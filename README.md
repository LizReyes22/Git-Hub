Finalmente en el archivo **Supermarket_Mapas** visualizamos el análisis anual de un supermercado, utilizando **Data Studio**; con el objetivo de:
- Calcular el promedio de ventas por Línea de Producto
- Calcular la cantidad(dólares) máxima de ventas durante el año
- Mostrar la facturación de Venta de acuerdo al tipo de pago
- Ranking de los items más vendidos de acuerdo a la línea del producto
- Promedio de ventas semanal por medio de barras apiladas, tomando en cuenta la línea del producto
